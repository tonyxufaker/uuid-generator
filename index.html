What is a UUID?

A UUID (Universally Unique Identifier) is a 128-bit label written as 36 characters, for example 123e4567-e89b-42d3-a456-426614174000. Developers use UUIDs to give things like database records, files, users, or orders an ID that is extremely unlikely to ever repeat, without needing a central system to hand out numbers.

What is a UUID v4?

Version 4 is the most common type of UUID. It is built from random numbers, so it does not contain any information about time or your device.

Can two generated UUIDs be the same?

In practice, no. The number of possible v4 UUIDs is so large that a duplicate is astronomically unlikely.
